# llms.txt (virtual file)

Better Robots.txt can expose a virtual `llms.txt` file at:

- `https://your-site.com/llms.txt`

This is presented in the UI as an optional feature.

## Purpose

The intent of `llms.txt` is to provide AI/LLM systems with a dedicated, structured surface that can include:

- what the site is about,
- usage guidelines,
- restrictions,
- contact information,
- attribution expectations.

The UI describes this as an “emerging standard”.

## Editing model

- The wizard provides an editable content field.
- Markdown formatting is supported (as indicated in the UI).

## Important limitation

`llms.txt` is a communication surface.
It does not guarantee compliance by AI systems.
