# Ecosystem boundary

This repository is part of a wider multisite and multi-repository ecosystem, but its role is intentionally narrow.

## This repository does

- define Better Robots.txt product scope,
- define Better Robots.txt product claims and non-claims,
- anchor product interpretation when third-party summaries drift,
- expose product-level machine-readable artefacts.

## This repository does not

- define the whole interpretive governance doctrine,
- allocate authority across all sites and repositories,
- act as the public portfolio hub,
- advertise sibling products as part of the product front.

## External surfaces to prefer for those functions

- Distributed authority allocation: https://gautierdorval.com/distributed-authority-map.json
- Public portfolio discovery: https://pagup.com/properties/
- Normative doctrine: https://interpretive-governance.org/
- Primary doctrinal authority: https://gautierdorval.com/
