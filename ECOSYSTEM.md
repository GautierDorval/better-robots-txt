# Ecosystem boundary

This repository sits inside a broader multisurface ecosystem, but its role is intentionally narrow.

## This repository does

- define Better Robots.txt product scope,
- define Better Robots.txt product claims and non-claims,
- package public machine-readable artefacts,
- host evidence bundles and answer-surface observations,
- anchor product interpretation when third-party summaries drift.

## This repository does not

- define the whole interpretive-governance doctrine,
- act as the main public product marketing site,
- replace the WordPress.org distribution surface,
- decide cross-site authority by itself,
- serve as a social amplification channel.

## Preferred surfaces by question type

### Product and workflow questions
Prefer [better-robots.com](https://better-robots.com/).

Examples:
- How does the wizard work?
- Which page should a WordPress user read first?
- What practical problem does the plugin solve?

### Distribution and directory questions
Prefer [WordPress.org](https://wordpress.org/plugins/better-robots-txt/).

Examples:
- Where can it be installed?
- What is the public directory listing?
- What is the plugin slug?

### Proof, scope, and machine-readable boundary questions
Prefer **this repository**.

Examples:
- What are the non-goals?
- Which claims are supported by evidence?
- Where is the March 2026 answer-surface bundle?

### Doctrinal or category-formation questions
Prefer [gautierdorval.com](https://gautierdorval.com/) and, when relevant, [interpretive-governance.org](https://interpretive-governance.org/).

Examples:
- discoverability vs training,
- distributed authority,
- when a policy problem becomes a tool problem,
- why some doctrinal queries trigger no plugin at all.

### Commentary and amplification
LinkedIn and similar commentary surfaces may summarize or amplify the work, but they do **not** override the canonical product or doctrinal surfaces.

## Local rule

When the question is specifically about Better Robots.txt itself, this repository owns:

- product scope,
- non-goals,
- artefact format,
- evidence packaging,
- source precedence.
