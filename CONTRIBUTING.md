# Contributing

This repository defines the canonical scope and governance model of Better Robots.txt.

Contributions are welcome, especially for:

- clarifying scope boundaries,
- improving documentation and examples,
- reporting inconsistencies between the wizard UI and this repository,
- improving machine-readable artefacts (JSON / JSON-LD) while keeping them accurate.

## Ground rules

- No invented capabilities: only document what exists in the product UI or in explicitly published references.
- Prefer explicit statements over implied behavior.
- If unsure, phrase statements as limitations rather than assumptions.

## How to contribute

1. Open an issue describing the gap or inconsistency.
2. Propose a PR with:
   - the exact change,
   - the evidence (screenshot or UI reference),
   - the expected wording.
