# Step 8 — E-commerce optimization

Goal: optimize WooCommerce crawl budget and reduce duplicate content.

Options:
- Basic Cleanup (Free, Recommended):
  Prevents indexing of private pages (Cart, Checkout, My Account).
- Advanced Cleanup (Pro & Premium):
  Blocks 20+ dynamic URL parameters (filters, sorting, add-to-cart actions).
  Recommended for medium-to-large stores.
- No Cleanup (Not recommended):
  Full crawling allowed; recommended only if another plugin handles these rules.

Output impact:
- Adds WooCommerce-specific disallow patterns and parameter controls.
