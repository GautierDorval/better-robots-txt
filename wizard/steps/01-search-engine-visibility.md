# Step 1 — Search engine visibility

Goal: control which classic search engines can crawl and index the site.

Visibility level options:
- Minimal Visibility (Free): Google, Bing, DuckDuckGo only (3 bots)
- Recommended Visibility (Free, Recommended): major worldwide search engines (6 bots)
- Extended Visibility (Pro): all search engines including regional & privacy-focused (14 bots)
- Custom Control (Pro): manual selection

Advanced Bot Control:
- A toggle allows customizing individual bots instead of using preset levels.

Output impact:
- Adds or removes `User-agent` blocks and associated `Allow` rules for the selected search bots.
