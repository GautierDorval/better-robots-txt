# Step 10 — Social media crawlers

Goal: control whether social platforms can crawl the site to build link previews.

Control:
- Block Social Media Crawlers (toggle):
  Prevents platforms like Facebook, Twitter/X, LinkedIn from fetching link previews.
  UI note: “Not recommended for public sites.”

Informational box:
- Explains that social previews (title, image, description) are generated by these crawlers and blocking them prevents previews.

Output impact:
- Adds blocks for preview crawlers when enabled.
