# Step 0 — Mode selection

Goal: choose a starting policy that fits your site and risk profile.

Available modes (UI cards):
- Mode 1: Essential (Free) — “clean robots.txt without complexity”
- Mode 2: AI-First (Pro) — “AI-ready without shutting down traffic” (recommended if you publish content)
- Mode 3: Fortress (Premium) — “maximum protection”
- Mode 0: Custom (Expert) — build rules module by module

UX notes:
- The screen includes a short product introduction, key benefits, and a “Setup in 3 clicks” section:
  1) choose a preset, 2) click “Configure”, 3) review preview & save.
- A clear reassurance line is present: “A preset + Save Changes is enough for 95% of sites.”
