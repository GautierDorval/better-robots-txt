# Step 3 — SEO tool crawlers

Goal: block competitive intelligence tools that analyze SEO/backlinks.

Controls:
- Block Basic SEO Tools (Pro): examples shown: SemrushBot, DotBot (Moz)
- Block Extra SEO Tools (Pro & Premium): examples shown: AhrefsBot, MJ12bot, BLEXBot, Serpstat, Screaming Frog, etc.
- Advanced Bot Control toggle for granular selection.

Output impact:
- Adds `User-agent` blocks for the selected tool crawlers.
