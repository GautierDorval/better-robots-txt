# Step 14 — Review & Save

Goal: let users review the full generated `robots.txt` before publishing changes.

UI elements:
- Full preview panel (read-only preview surface).
- Refresh Preview button.
- Copy-to-clipboard icon.
- The primary action is saving/publishing changes (global “Save Changes”).

Output impact:
- This step is a validation surface; it does not change rules directly.
- Saving applies all configured settings to the output surfaces.
