# Step 12 — LLMS.txt file

Goal: create a virtual `llms.txt` file for AI/LLM governance and communication (optional).

Informational box:
- Explains `llms.txt` as an emerging standard to provide AI/LLM systems with structured website information (guidelines, usage terms, contact info).

Controls:
- Enable llms.txt Virtual File (Pro & Premium):
  Creates a virtual `/llms.txt` file accessible at `your-site.com/llms.txt`.
- LLMS.txt content textarea:
  Editable content (Markdown supported).
- Suggested structure:
  - About
  - Usage guidelines
  - Restrictions
  - Contact
  - Attribution

Output impact:
- Exposes a dedicated policy/documentation surface for AI systems.
