# Step 11 — Revenue & monetization

Goal: ensure monetization verification files remain accessible.

Controls:
- Allow verification file (`ads.txt`) (Recommended): allows ad networks (Google AdSense, Media.net, etc.) to verify site ownership.
- Allow app verification file (`app-ads.txt`) (Free): required for in-app advertising verification.

Output impact:
- Adds `Allow` rules for these verification files.
