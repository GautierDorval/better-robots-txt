# Wizard reference

The Better Robots.txt wizard is designed to be:

- **preset-driven** for speed (novice-friendly),
- **module-driven** for control (expert-friendly),
- **reviewable** (final preview before saving).

The wizard flow is defined in `steps/`:

- 00: Mode selection
- 01: Search engine visibility
- 02: AI & LLM governance
- 03: SEO tool crawlers
- 04: Bad bots protection
- 05: Archive & Wayback control
- 06: Global settings
- 07: Spam, feeds & crawl traps
- 08: E-commerce optimization
- 09: Resources & assets
- 10: Social media crawlers
- 11: Revenue & monetization
- 12: LLMS.txt file
- 13: Advanced settings
- 14: Review & Save

Screenshots are stored in `../assets/screenshots/`.
